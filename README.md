## Городской симулятор (City Simulation)

Веб‑приложение для проведения имитационной игры по соучаствующему проектированию городской территории: участники получают игровые роли (команды), вносят решения по параметрам, подтверждают их в раундах, а модератор видит агрегаты, конфликтность и протокол.

## Исследовательская работа

Проект разрабатывается как **исследовательская работа** в **Институте дизайна и урбанистики ИТМО**.

## Как запустить локально

- Откройте `index.html` в браузере (Chrome/Safari/Firefox).
- Если требуется онлайн‑синхронизация (модератор + участники на разных устройствах), настройте Firebase в `app.js` (блок `FIREBASE_CONFIG`).

## Ключевые режимы

- **Модератор**: управление фазами, события, матрица параметров, метрики, экспорт протокола.
- **Участник**: решения в раундах (фазы 1 и 4), подтверждение, сравнение команд (паспорт/радар/конфликт).
- **Демонстрация**: read‑only подключение по коду сессии.
